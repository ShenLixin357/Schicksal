Insaniquarium Deluxe - independent browser engine port

This is a community port based on restored game code, not an official EA release.
Original game graphics, music and sounds are supplied by this private site's
owner and load automatically for authenticated members. Players do not need
to provide a ZIP or an installed game folder. Retail assets are excluded from
the engine source archive linked below.

Original game: PopCap Games / Flying Bear Entertainment.
WinFish decompilation: https://github.com/Vindirect/WinFish
Native port and PopLib fork: https://github.com/SaMeiers/insaniquarium-port
Exact upstream revisions: ../engine/build.json
Framework/port license: ../engine/LICENSE-AGPL-3.0.txt

Schicksal browser adapters and build instructions:
https://github.com/ShenLixin357/Schicksal/tree/feature/chryser-aquarium-cloud-save/ports/insaniquarium

Download the matching prepared source: ./insaniquarium-source.tar.gz
Its SHA-256 is recorded in ../engine/build.json. It includes the pinned native
source, dependencies and browser adapters, with rebuild instructions in ports/.
Retail assets are excluded. The source archive is served behind the same member
login as the engine.
