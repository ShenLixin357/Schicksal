# Gallery B — first isolated artwork browsing slice (2026-11-28)

Baseline: 29a76314815c7a8852feb70295510af42ec26652. Separate development branch; no production merge, deployment, database write, R2 subscription or storage access authorized.

- Reuses the existing Gallery list, pagination, review, download and history APIs.
- Grid loads thumbnail bytes only when close to the viewport. It never silently downloads full originals or high-resolution previews.
- A keyboard-accessible native modal opens the existing authorized preview endpoint; full original viewing is an explicit action. Blob URLs and in-flight requests are released on close/unmount/role changes.
- Artwork-first neutral paper palette, responsive frames, restrained typography, touch and reduced-motion states.
- No fabricated artwork, no fake storage metrics. Existing gallery feature gates remain off.

Remaining: integrated visual review, unified mixed-file batch intake, category/project relationship data, full review enforcement across all read paths, actual storage quota/operation budget reservation, backups and restore validation, private archive, ZIP/document intake and actual browser tests.
